# Yellow Zone Admin

لوحة الإدارة الرسمية لموقع Yellow Zone.

## تسجيل الدخول
- الدخول يتم عبر Supabase Auth بالبريد الإلكتروني وكلمة المرور.
- لا توجد كلمات مرور موظفين محفوظة داخل ملفات الموقع.
- الصلاحيات مرتبطة بحساب Supabase عبر جدول `admin_users`.

الأدوار:
- إيمان: full
- آلاء: pricing_ads

## الأقسام
- الحجوزات
- الأسعار والباقات
- الإعلانات والفعاليات
- المعرض
- التقييمات والتعليقات

التقييمات تعرض التقييمات الجيدة والسيئة الموجودة، ويمكن للأدمن إظهار أو إخفاء أو حذف أي تقييم.
